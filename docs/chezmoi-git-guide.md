# Using Git with Chezmoi

Guide to version controlling your dotfiles with git and chezmoi.

## Basic Concepts

Chezmoi stores your dotfiles in a **source directory** (typically `~/.local/share/chezmoi`), which is a regular git repository. Chezmoi transforms and deploys these files to your **home directory**.

```
Source State (git repo)          Target State (home directory)
~/.local/share/chezmoi/    -->   ~/
├── dot_zshrc              -->   .zshrc
├── dot_config/nvim/       -->   .config/nvim/
└── encrypted_dot_gitconfig.age  -->   .gitconfig
```

## Daily Workflow

### Making Changes

There are two approaches to editing managed files:

#### Option 1: Edit via Chezmoi (Recommended)

```bash
# Edit a file (opens in $EDITOR, updates source automatically)
chezmoi edit ~/.zshrc

# After editing, apply to verify
chezmoi apply
```

#### Option 2: Edit Target, Then Re-add

```bash
# Edit the file directly
nvim ~/.zshrc

# Pull changes back into chezmoi source
chezmoi re-add
```

### Committing Changes

After making changes, commit them in the source directory:

```bash
cd ~/.local/share/chezmoi

# Check what changed
git status
git diff

# Commit
git add -A
git commit -m "Update zsh configuration"
```

Or use chezmoi's built-in git passthrough:

```bash
chezmoi git status
chezmoi git diff
chezmoi git add -A
chezmoi git commit -m "Update zsh configuration"
```

### Pushing and Pulling

```bash
# Push to remote
chezmoi git push

# Pull from remote
chezmoi git pull

# Apply pulled changes
chezmoi apply
```

Or combine pull and apply:

```bash
chezmoi update
```

## Setting Up a New Machine

### Initial Clone

```bash
# Clone and apply in one command
chezmoi init --apply https://github.com/username/dotfiles.git

# Or clone without applying (to review first)
chezmoi init https://github.com/username/dotfiles.git
chezmoi diff
chezmoi apply
```

### With SSH

```bash
chezmoi init --apply git@github.com:username/dotfiles.git
```

### With Encryption (This Repo)

This repo stores the age key in KeePassXC, so setup is automatic:

```bash
# 1. Ensure KeePassXC database is available (e.g., via Syncthing)
# 2. Init - this prompts for your KeePassXC password and extracts the key
chezmoi init git@github.com:username/dotfiles.git

# 3. Apply
chezmoi apply
```

The `.chezmoi.toml.tmpl` configures KeePassXC automatically, and the age key is pulled from the "Chezmoi" entry.

### With Encryption (Manual Key)

For repos without KeePassXC integration, copy the key manually:

```bash
# Create chezmoi config directory
mkdir -p ~/.config/chezmoi

# Copy your age key (from secure backup)
cp /path/to/backup/key.txt ~/.config/chezmoi/key.txt
chmod 600 ~/.config/chezmoi/key.txt

# Create config pointing to key
cat > ~/.config/chezmoi/chezmoi.toml << 'EOF'
encryption = "age"

[age]
    identity = "~/.config/chezmoi/key.txt"
    recipient = "age1your-public-key-here"
EOF

# Now init and apply
chezmoi init --apply git@github.com:username/dotfiles.git
```

## Handling Merge Conflicts

When `chezmoi update` encounters conflicts:

```bash
# Pull changes without applying
chezmoi git pull

# Check the source state
cd ~/.local/share/chezmoi
git status

# Resolve conflicts in source files
nvim dot_zshrc  # fix conflicts

# Mark resolved and commit
git add dot_zshrc
git commit -m "Resolve merge conflict in zshrc"

# Apply the resolved state
chezmoi apply
```

## Keeping Source and Target in Sync

### Check for Drift

```bash
# Show what would change if you applied
chezmoi diff

# Verbose output
chezmoi diff --verbose
```

### Re-add All Modified Files

If you've edited target files directly:

```bash
# Re-add all managed files that have changed
chezmoi re-add

# Then commit
chezmoi git add -A
chezmoi git commit -m "Re-add modified files"
```

### Verify State

```bash
# List all managed files
chezmoi managed

# Show source path for a target file
chezmoi source-path ~/.zshrc
```

## Working with Branches

Use branches for experimental changes or machine-specific configs:

```bash
cd ~/.local/share/chezmoi

# Create feature branch
git checkout -b experiment/new-shell-config

# Make changes
chezmoi edit ~/.zshrc
chezmoi apply

# If it works, merge to main
git checkout main
git merge experiment/new-shell-config
git push
```

## Ignoring Generated Files

Some files are generated by applications and shouldn't be tracked. Add them to `.chezmoiignore`:

```bash
# .chezmoiignore
README.md
LICENSE

# Generated theme files (managed by wallust)
dot_config/alacritty/colors.toml
dot_config/waybar/colors.css
```

For files already in the repo that are auto-generated (like theme files), use git's assume-unchanged:

```bash
# Mark file as unchanged (stops tracking modifications)
git update-index --assume-unchanged dot_config/waybar/colors.css

# Undo if needed
git update-index --no-assume-unchanged dot_config/waybar/colors.css
```

## Automated Commits

### Git Auto-commit on Apply

Add to `~/.config/chezmoi/chezmoi.toml`:

```toml
[git]
    autoCommit = true
    autoPush = true  # Optional: also push after each apply
```

Now `chezmoi apply` will automatically commit changes.

### Pre-commit Hooks

Create `.pre-commit-config.yaml` in your chezmoi source directory:

```yaml
repos:
  - repo: https://github.com/pre-commit/pre-commit-hooks
    rev: v4.5.0
    hooks:
      - id: trailing-whitespace
      - id: end-of-file-fixer
      - id: check-yaml
      - id: check-added-large-files
```

## Quick Reference

| Task | Command |
|------|---------|
| Edit and apply | `chezmoi edit ~/.file && chezmoi apply` |
| Re-add changed files | `chezmoi re-add` |
| Check diff | `chezmoi diff` |
| Commit changes | `chezmoi git add -A && chezmoi git commit -m "msg"` |
| Push to remote | `chezmoi git push` |
| Pull and apply | `chezmoi update` |
| Init new machine | `chezmoi init --apply <repo-url>` |
| View source path | `chezmoi source-path ~/.file` |
