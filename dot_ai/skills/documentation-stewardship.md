# Documentation Stewardship Skill

## Procedure

1. Read existing docs before writing.
2. Update existing docs before adding new docs.
3. Document why, usage, boundaries, invariants, and operational consequences.
4. Avoid paraphrasing implementation details that are obvious from code.
5. Keep docs short enough to stay maintained.

## Output

State what confusion the documentation removes and where the durable source of truth now lives.
