# Important Rules to Follow
## Comments
- Only add comments to code when explicitly requested by a human. If you believe a comment is of utmost importance, explain why and ask for permission first.

## Markdown
- README files are okay to update to add documentation that typically belongs in a README, otherwise you do not make changes to markdown files unless explicitly requested by a human. If you believe adding or updating a markdown document is of utmost importance you explain why and ask for permission first.
