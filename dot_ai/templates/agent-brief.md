# Agent Brief

## Outcome

One sentence describing the behavior that should exist when the work is complete.

## Current Behavior

What happens now, including the observable failure or limitation.

## Desired Behavior

What should happen, including important edge cases and error behavior.

## Constraints

- Durable project rules, compatibility needs, or interfaces to preserve.

## Relevant Interfaces

- Stable types, commands, APIs, configuration shapes, or paths that reduce discovery cost.

## Acceptance Criteria

- [ ] Independently observable criterion.
- [ ] Verification through the real artifact or user path.

## Out of Scope

- Adjacent work the agent must not add.

Describe behavior rather than implementation steps. Avoid line numbers and brittle details. Include stable paths only when they materially reduce search cost.
